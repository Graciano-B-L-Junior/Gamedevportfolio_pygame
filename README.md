# Game dev portfolio pygame

This is a portfolio of game development projects using Pygame.

## Projects

### 1. Flappy Bird

A recreation of the classic mobile game Flappy Bird. The player controls a bird that must navigate through a series of pipes without hitting them. The game features:

-   Simple one-button controls.
-   Procedurally generated pipes for endless gameplay.
-   Score tracking.
-   Game over screen with restart option.

### 2. Platform game

A classic 2D platformer game. The player controls a character that runs and jumps across platforms to reach the end of the level. The game features:

-   Physics-based movement including gravity and jumping.
-   Coyote Jump mechanic,
-   Visual hit feedback on player and enemy
-   Sound effects and music.
-   Tile-based level design with various obstacles.
-   Enemy collision mechanics.
-   Collectibles and scoring.
